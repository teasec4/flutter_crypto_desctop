================================================================================
                           DATA FLOW DIAGRAM
================================================================================

REGISTRATION FLOW:
─────────────────

User Input (email, password, displayName)
    │
    ▼
RegisterPage validates form
    │
    ▼
AuthCubit.register() emits AuthLoading
    │
    ▼
AuthRepository.register()
    │
    ├─→ AuthRemoteDataSource.register()
    │       │
    │       ├─→ Firebase Auth: createUserWithEmailAndPassword()
    │       ├─→ Firebase Auth: updateProfile(displayName)
    │       └─→ Firestore: Save user to users/{email}
    │
    └─→ UserLocalDataSource.saveUser()
            │
            └─→ Isar: Save user to local database
    │
    ▼
AuthCubit emits AuthSuccess
    │
    ▼
UI navigates to /home


LOGIN FLOW:
──────────

User Input (email, password)
    │
    ▼
LoginPage validates form
    │
    ▼
AuthCubit.login() emits AuthLoading
    │
    ▼
AuthRepository.login()
    │
    ├─→ AuthRemoteDataSource.login()
    │       │
    │       └─→ Firebase Auth: signInWithEmailAndPassword()
    │
    └─→ UserLocalDataSource.saveUser()
            │
            └─→ Isar: Cache user locally
    │
    ▼
AuthCubit emits AuthSuccess
    │
    ▼
UI navigates to /home


LOGOUT FLOW:
───────────

User Action: Click Logout in Settings
    │
    ▼
Confirmation Dialog
    │
    ▼
AuthCubit.logout() emits AuthLoading
    │
    ▼
AuthRepository.logout()
    │
    ├─→ Get current user
    ├─→ AuthRemoteDataSource.logout()
    │       │
    │       └─→ Firebase Auth: signOut()
    │
    └─→ UserLocalDataSource.deleteUser()
            │
            └─→ Isar: Remove user from local database
    │
    ▼
AuthCubit emits AuthInitial
    │
    ▼
UI navigates to /login
